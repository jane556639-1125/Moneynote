💰 Moneynote｜我的記帳

讓記帳成為生活習慣，讓每一筆金錢都有跡可循。

一款簡潔、直覺的個人記帳與財務管理 Web App，整合日常收支、銀行帳戶、現金管理及信用卡消費紀錄，讓使用者能夠快速掌握個人財務狀況。

支援 iPhone、iPad 及電腦瀏覽，無須安裝額外軟體，即可開始使用。

🌐 線上使用

開啟 Moneynote 記帳 App

✨ 核心功能

📝 記帳明細

* 新增收入及支出紀錄
* 日期預設為當天
* 消費分類及付款帳戶選擇
* 金額與備註紀錄
* 依月份、分類及帳戶篩選
* 自動統計總收入、總支出及收支淨額
* CSV 匯出，支援 Excel 開啟

📊 費用整理

* 各帳戶收入與支出統計
* 銀行及現金餘額統計
* 信用卡未繳金額統計
* 扣除信用卡債務後的財務淨額
* 支援月份及全部期間查詢
* 淨額大於或等於零：黑色數字
* 淨額小於零：紅色數字

🏦 帳戶管理

* 支援銀行、現金及信用卡帳戶
* 自訂新增及修改帳戶
* 設定期初餘額
* 設定信用卡期初未繳金額
* 帳戶停用及重新啟用
* 安全刪除符合條件的帳戶
* 保留歷史交易紀錄

💳 轉帳與信用卡繳款

* 銀行帳戶間資金轉移
* 現金提領與存入
* 信用卡繳款紀錄
* 自動調整帳戶餘額
* 避免轉帳及繳卡費重複計入生活支出

📱 加入手機主畫面

1. 使用 Safari 開啟 Moneynote 網站。
2. 點選分享按鈕。
3. 選擇「加入主畫面」。
4. 點選「新增」。

即可像一般 App 一樣，從手機或平板主畫面快速開啟。

🔒 資料保存與隱私

* 使用瀏覽器 localStorage 儲存資料。
* 不需要註冊額外帳號。
* 不會主動將記帳資料傳送至伺服器。
* 不會連接銀行或取得網銀資料。
* 重新整理頁面後仍可保留紀錄。
* 建議定期匯出 CSV 備份交易明細。

注意：清除瀏覽器網站資料、更換裝置或網站來源，可能造成原有資料無法存取。目前尚未提供跨裝置同步及完整資料還原功能。
