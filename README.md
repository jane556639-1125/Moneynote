# 💰 Moneynote｜我的記帳

> 讓記帳成為生活習慣，讓每一筆金錢都有跡可循。

一款簡潔、直覺的個人記帳與財務管理 Web App，整合日常收支、銀行帳戶、現金管理、信用卡消費及帳單核對。支援 iPhone、iPad 及電腦瀏覽，無須安裝額外軟體。

**目前正式版本：V5.4｜2026.11.24**

## ✨ 核心功能

### 1. 📝 記帳明細

- 新增收入及支出，日期預設為當天。
- 記錄分類、帳戶、金額及備註。
- 依月份、分類及帳戶篩選，支援清除篩選及 CSV 匯出。
- 自動統計收入、支出及收支淨額。

### 2. 📊 費用整理

- 各帳戶收支、銀行及現金餘額、信用卡未繳金額統計。
- 支援月份及全部期間查詢。
- 計算扣除信用卡債務後的財務淨額。
- 收入、銀行及現金採藍色；支出及信用卡採玫瑰紅；非負淨額採黑色，負淨額採紅色。

### 3. 🏦 帳戶管理

- 支援銀行、現金及信用卡帳戶，自訂名稱與期初餘額。
- 設定信用卡結帳日、繳款日及期初未繳金額。
- 支援帳戶停用、重新啟用及符合條件的安全刪除，保留歷史交易。
- JSON 完整資料備份與還原功能位於本頁下方。

### 4. 💳 轉帳／繳卡費

- 支援銀行轉帳、現金提領與存入及信用卡繳款。
- 自動調整帳戶餘額，避免轉帳及繳卡費重複計入生活支出。

### 5. 📋 帳單核對

- 選擇信用卡及帳單月份，依結帳日自動計算刷卡日期範圍，填寫最後繳款截止日與銀行帳單金額。
- 逐筆核對消費，支援尚未核對、核對相符、金額異常及本期未入帳。
- 支援跨期入帳與差額處理，依情況修正原始紀錄或新增帳務調整。
- 帳單差異為獨立附加功能，輸入表單預設收合；支援漏記消費、海外交易手續費、退款／刷卡金回饋等項目。
- 已新增的差異明細持續顯示，筆數自動更新。
- 自動儲存核對進度，符合完成條件後可完成本期核對，亦可重新開啟。

## 📱 加入手機主畫面

1. 使用 Safari 開啟正式版網站。
2. 點選分享按鈕。
3. 選擇「加入主畫面」。
4. 點選「新增」。

即可從手機或平板主畫面快速開啟。此功能不代表完整離線支援。

## 🔒 資料保存與隱私

- 使用瀏覽器 localStorage 儲存資料，無須註冊帳號。
- 不主動將記帳資料傳送至伺服器，不連接銀行或網銀。
- 正式版與測試版使用不同的儲存識別碼，資料各自獨立。
- CSV 適用於交易明細整理；JSON 用於完整帳務備份與還原。
- 目前不提供自動跨裝置或 iCloud 同步。可手動將 JSON 備份存至 iCloud Drive，再於其他裝置還原。

### 備份與還原

1. 進入「帳戶管理」下方的資料備份區。
2. 匯出 JSON 並保存至安全位置。
3. 如需還原，先備份目前資料，再選擇正確的 JSON 檔案並確認操作。

**注意：** 還原可能覆蓋現有資料。清除瀏覽器網站資料、更換裝置或網站來源，可能造成原有資料無法存取。請定期備份，避免將含個人財務資訊的 JSON 或 CSV 上傳至公開 GitHub 儲存庫。
